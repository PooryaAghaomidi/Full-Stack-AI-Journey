## Introduction

Software on Linux is managed through **package managers**, which automate downloading, installing, updating, configuring, and removing programs.  
For a full-stack AI developer, being fluent with Linux package systems is essential to:

- install development tools  
- manage Python, Node, and AI libraries  
- configure environments  
- build dependencies for ML frameworks (PyTorch, TensorFlow)  
- maintain healthy systems  

This tutorial covers **package managers**, **software installation methods**, and **critical Linux developer tools**.

---

## What Are Package Managers?

A **package manager** is a system that handles software installation, updates, dependencies, and removal.

Examples:

- `apt` — Debian/Ubuntu  
- `dnf` — Fedora/RHEL  
- `snap` — Universal packages  
- `flatpak` — Sandboxed application packages  

### Why Developers Need Them

- Install tools like **git**, **python3**, **docker**, **gcc**, **nodejs**  
- Manage system libraries  
- Keep your system updated  
- Resolve dependency issues automatically  

---

## APT: Advanced Package Tool (Debian/Ubuntu)

APT is the package management system used by **Ubuntu, Debian, Linux Mint**, and many popular distros.

### Updating the System

```bash
sudo apt update
sudo apt upgrade
```

- `update`: refreshes the package index  
- `upgrade`: installs the newest versions  

### Installing Packages

```bash
sudo apt install package-name
```

Example:

```bash
sudo apt install git python3-pip build-essential
```

### Removing Packages

```bash
sudo apt remove package-name
sudo apt purge package-name    # removes config files too
```

### Searching for Packages

```bash
apt search editor
apt show neovim
```

### Fixing Broken Dependencies

```bash
sudo apt --fix-broken install
```

## RPM & DNF (Fedora, RHEL)

Fedora and Enterprise Linux use **RPM packages** with **DNF** as the primary manager.

### Install

```bash
sudo dnf install package-name
```

### Update

```bash
sudo dnf update
```

### Remove

```bash
sudo dnf remove package-name
```

---

## Snap Packages

Snaps are **containerized**, **self-updating** applications maintained by Canonical.

### Install Snap

```bash
sudo apt install snapd
sudo snap install package-name
```

### Example

```bash
sudo snap install code --classic
```

Snaps:

- contain their dependencies  
- update automatically  
- great for cross-distro support  

---

## Flatpak

Another universal package system focusing on sandboxing and security.

### Setup

```bash
sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

### Install Apps

```bash
flatpak install flathub com.visualstudio.code
```

## Package Repositories & PPAs

Sometimes official repositories lack the latest versions.

On Ubuntu, you can use **PPAs** (Personal Package Archives):

```bash
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.11
```

Use PPAs carefully — they can break systems if not maintained.

## Installing Software from Source

Many AI/ML tools may require custom builds.

### Typical Steps

```bash
./configure        # checks your system, finds dependencies, and prepares build files
make               # compiles the source code into binaries
sudo make install  # installs the compiled binaries into system directories (e.g., /usr/local/bin)
```

### Advantages

- Latest version  
- Custom build options  

### Disadvantages

- No automatic updates  
- Harder to uninstall  
- Requires build tools  

Install build tools on Ubuntu:

```bash
sudo apt install build-essential
```

## Language-Specific Package Managers

These are essential for AI and full-stack work.

---

### Python: pip & virtualenv

Install pip:

```bash
sudo apt install python3-pip
```

Install a package:

```bash
pip install numpy
```

Virtual environments:

```bash
pip install virtualenv
virtualenv venv
source venv/bin/activate
```

---

### Node.js: npm & yarn

Install Node:

```bash
sudo apt install nodejs npm
```

Install packages:

```bash
npm install express
```

Install yarn:

```bash
npm install --global yarn
```

---

### Rust: cargo

```bash
sudo apt install cargo
cargo new app
cargo build
```

---

### Go: Go Modules

```bash
sudo apt install golang-go
```

Inside project:

```bash
go mod init app
go get package-name
```


### System Monitoring Tools

```bash
sudo apt install htop
sudo apt install nmon
```

---

## Best Practices

- Update regularly  
- Prefer official repositories before PPAs  
- Use virtual environments for Python  
- Keep language-specific package systems separate from system packages  
- Avoid installing from source unless necessary  
- Remove unused packages:

```bash
sudo apt autoremove
```
