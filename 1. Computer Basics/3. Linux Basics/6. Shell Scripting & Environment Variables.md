## Introduction

Shell scripting is one of the most important skills for Linux developers—especially full-stack AI developers who automate workflows, configure environments, manage datasets, and orchestrate training jobs.

This tutorial gives you everything you need to:

- write shell scripts  
- automate tasks  
- manage environment variables  
- configure persistent system settings  
- optimize development environments  

---

## What Is Shell Scripting?

A **shell script** is a file containing commands executed by the shell (usually **bash**, **zsh**, or **sh**).

Uses:

- Automating installations  
- Running ML experiments  
- Processing datasets  
- Managing servers  
- Environment setup  

---

## Getting Started With Shell Scripts

### Creating a Script

```bash
nano hello.sh
```

Add:

```bash
#!/bin/bash
echo "Hello World!"
```

The first line (`#!/bin/bash`) is a **shebang** that tells Linux which interpreter to use.

---

### Making Scripts Executable

```bash
chmod +x hello.sh
```

---

### Running Scripts

Run in two ways:

```bash
./hello.sh
```

or

```bash
bash hello.sh
```

## Shell Script Basics

### Variables

```bash
name="Alice"
echo "Hello $name"
```

No spaces around `=` allowed.

---

### Arguments (`$1`, `$2`, `$@`, etc.)

Shell scripts can access the values passed to them on the command line using positional parameters like `$1` (first argument), `$2` (second argument), and `$@` (all arguments).

```bash
echo "First arg: $1"   # prints the first argument provided to the script
echo "All args: $@"    # prints all arguments as a space-separated list
```

Run:

```bash
./script.sh param1 param2   # here param1 → $1 and param2 → $2
```

---

### User Input

```bash
read -p "Enter your name: " name
echo "Hello $name"
```

---

### Conditionals (`if`, `else`)

```bash
#!/bin/bash

if [ $1 -gt 10 ]; then
  echo "Greater than 10"
else
  echo "10 or less"
fi
```

---

### Loops (`for`, `while`)

#### For Loop

```bash
for i in {1..5}; do
  echo "Number $i"
done
```

#### While Loop

```bash
count=1
while [ $count -le 5 ]; do
  echo "Count $count"
  ((count++))
done
```

---

### Functions

```bash
greet() {
  echo "Hello, $1"
}

greet "Bob"
```

---

### Exit Codes

Exit code `0` = success.  
Non-zero = error.

```bash
exit 0
```

Check exit code of previous command:

```bash
echo $?
```

## Useful Shell Scripting Tools

### `cron` Jobs

Automate recurring tasks (backups, cleanup, ML jobs).

Edit cron:

```bash
crontab -e
```

Run a script every day at 3am:

```bash
0 3 * * * /home/user/scripts/backup.sh
```

---

### `set` Options (Error Handling)

Stop script on error:

```bash
set -e
```

Print commands as they run:

```bash
set -x
```

---

### Script Debugging

Run a script in debug mode:

```bash
bash -x script.sh
```

## Environment Variables

### What They Are

Environment variables store data used by:

- the shell  
- operating system  
- applications  

Examples:

- `PATH`  
- `HOME`  
- `USER`  
- `PYTHONPATH`  
- `CUDA_HOME`  

---

### Viewing Variables

```bash
printenv
echo $HOME
echo $USER
```

---

### Setting Variables (Temporary & Permanent)

#### Temporary (current session)

```bash
export MY_VAR="hello"
```

#### Available for all programs in that shell

```bash
export PATH="$PATH:/my/custom/path"
```

#### Permanent (persistent)

Add to:

- `~/.bashrc` (most common)
- `~/.bash_profile`
- `~/.profile`

Example:

```bash
echo 'export MY_VAR="hello"' >> ~/.bashrc
source ~/.bashrc
```

---

### PATH Variable

The `PATH` variable tells the shell where to look for executables.

View:

```bash
echo $PATH
```

Add a directory:

```bash
export PATH="$PATH:/opt/myprogram/bin"
```

Make it permanent by adding to `.bashrc`.

---

### Environment Files (`.bashrc`, `.profile`, `.bash_profile`)

| File | Purpose |
|------|---------|
| `~/.bashrc` | Executed for interactive shells (most commonly edited) |
| `~/.profile` | Executed at login for all shells |
| `~/.bash_profile` | Executed at login (macOS uses this heavily) |

---

### Exporting Variables

```bash
export API_KEY="12345"
export CUDA_HOME="/usr/local/cuda"
```

---

### Unsetting Variables

```bash
unset API_KEY
```

---

## Environment Variables for Python & AI Development

### PYTHONPATH

Add custom Python modules:

```bash
export PYTHONPATH="$PYTHONPATH:/home/user/projects/myapp"
```

---

### Virtual Environment Activation

```bash
export PATH="$HOME/.local/bin:$PATH"
```

---

### CUDA Variables (for GPU development)

```bash
export CUDA_HOME=/usr/local/cuda
export PATH="$CUDA_HOME/bin:$PATH"
export LD_LIBRARY_PATH="$CUDA_HOME/lib64:$LD_LIBRARY_PATH"
```

---

### API Keys & Secrets

Never hardcode in code. Use environment variables:

```bash
export OPENAI_API_KEY="your-key"
```

---

## Best Practices

- Use `#!/bin/bash` at the top of scripts  
- Quote variables: `"${var}"`  
- Use `set -e` for safer scripts  
- Use cron for scheduled tasks  
- Keep environment variables in `.bashrc`  
- Never store private API keys in files or Git  
- Use environment variables to configure ML frameworks
