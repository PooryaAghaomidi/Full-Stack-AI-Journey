## Error Handling

JavaScript uses **try-catch-finally** for exceptions.

### Basic Example

```javascript
try {
    let result = 10 / 0;
    if (!isFinite(result)) throw new Error("Division by zero");
} catch (err) {
    console.log("Error:", err.message);
} finally {
    console.log("Execution complete");
}
```

### Throwing Custom Errors

```javascript
function divide(a, b) {
    if (b === 0) throw new Error("Cannot divide by zero");
    return a / b;
}
```

### Best Practices

- Always catch potential errors  
- Use `finally` for cleanup  
- Prefer meaningful error messages

## File I/O

Node.js provides the **fs** module for file operations.

### Reading Files

```javascript
const fs = require('fs');

fs.readFile('input.txt', 'utf8', (err, data) => {
    if (err) throw err;
    console.log(data);
});
```

### Writing Files

```javascript
fs.writeFile('output.txt', 'Hello JavaScript!', (err) => {
    if (err) throw err;
    console.log('File written successfully');
});
```

### Synchronous I/O

```javascript
const data = fs.readFileSync('input.txt', 'utf8');
console.log(data);
```

## Package Management

### npm (Node Package Manager)

- Initialize project: `npm init -y`  
- Install package: `npm install package-name`  
- Global install: `npm install -g package-name`  
- Remove package: `npm uninstall package-name`

### yarn

- Install Yarn: `npm install -g yarn`  
- Initialize project: `yarn init`  
- Install package: `yarn add package-name`

### Best Practices

- Lock dependency versions with `package-lock.json` or `yarn.lock`  
- Keep dependencies minimal  
- Update packages regularly

## Build Tools / Runtime Model

### Node.js Runtime

- Executes JavaScript outside browser  
- Uses **event loop** for non-blocking I/O  
- Single-threaded with asynchronous capabilities

### Build Tools

- **Webpack**: bundles frontend JS modules  
- **Babel**: transpiles modern JS to older standards  
- **Parcel / Vite**: fast frontend build tools

## Concurrency / Async

JavaScript is **single-threaded** but uses asynchronous patterns.

### Callbacks

```javascript
setTimeout(() => {
    console.log("Delayed execution");
}, 1000);
```

### Promises

```javascript
const promise = new Promise((resolve, reject) => {
    setTimeout(() => resolve("Success"), 1000);
});
promise.then(result => console.log(result));
```

### Async/Await

```javascript
async function fetchData() {
    try {
        let response = await fetch("https://api.example.com/data");
        let data = await response.json();
        console.log(data);
    } catch (err) {
        console.log("Error:", err);
    }
}
```

### Event Loop

- Executes callbacks from the **task queue**  
- Handles **microtasks** (`Promise.then`) before regular tasks  
- Key to non-blocking async execution

## Common Gotchas / Tips

- **Variable hoisting**: `var` is hoisted, `let/const` are block-scoped  
- **`this` keyword**: context changes in functions, arrow functions preserve it  
- **Floating-point precision**: beware of rounding errors  
- **Async pitfalls**: forgetting `await` leads to unresolved promises  
- **Falsy values**: `0`, `""`, `null`, `undefined`, `NaN`, `false`  
- **Comparison**: use `===` instead of `==` to avoid coercion  
- **Memory leaks**: avoid global variables and circular references  
- **Module paths**: ensure correct relative or absolute paths for imports/exports
