## Conditions

Conditional statements allow branching based on boolean expressions.

### `if` Statement

```javascript
let x = 10;
if (x > 5) {
    console.log("x is greater than 5");
}
```

### `if-else` Statement

```javascript
if (x % 2 === 0) {
    console.log("x is even");
} else {
    console.log("x is odd");
}
```

### `else if` Ladder

```javascript
if (x > 10) {
    console.log("x > 10");
} else if (x > 5) {
    console.log("x > 5");
} else {
    console.log("x <= 5");
}
```

### Ternary Operator

```javascript
let result = (x % 2 === 0) ? "even" : "odd";
console.log(result);
```

## Loops

### `for` Loop

```javascript
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

### `while` Loop

```javascript
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}
```

### `do-while` Loop

```javascript
let j = 0;
do {
    console.log(j);
    j++;
} while (j < 5);
```

### `break` and `continue`

```javascript
for (let i = 0; i < 10; i++) {
    if (i === 5) break;
    if (i % 2 === 0) continue;
    console.log(i);
}
```

## Functions

Functions allow encapsulation and reuse.

### Function Declaration

```javascript
function add(a, b) {
    return a + b;
}
console.log(add(3, 4));
```

### Function Expression

```javascript
const multiply = function(a, b) {
    return a * b;
};
```

### Arrow Functions

```javascript
const subtract = (a, b) => a - b;
```

### Parameters & Default Values

```javascript
function greet(name = "Guest") {
    console.log("Hello " + name);
}
```

### Scope

- `var`: function-scoped  
- `let` / `const`: block-scoped  
- Avoid global variables

## Object-Oriented Programming

JavaScript supports OOP through **prototypes** and **classes**.

### Prototypal OOP

```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
}
Person.prototype.greet = function() {
    console.log("Hello, my name is " + this.name);
};
let p = new Person("Alice", 25);
p.greet();
```

### Class Syntax (ES6+)

```javascript
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        console.log(`Hello, my name is ${this.name}`);
    }
}

let p = new Person("Alice", 25);
p.greet();
```

### Inheritance

```javascript
class Employee extends Person {
    constructor(name, age, position) {
        super(name, age);
        this.position = position;
    }

    work() {
        console.log(`${this.name} is working as ${this.position}`);
    }
}

let e = new Employee("Bob", 30, "Developer");
e.greet();
e.work();
```

### Encapsulation

- Use `#privateField` for private variables (ES2022+)  
- Methods can control access to internal state

## Modules / Imports

### Exporting

```javascript
// utils.js
export function add(a, b) { return a + b; }
export const PI = 3.14159;
```

### Importing

```javascript
// main.js
import { add, PI } from './utils.js';
console.log(add(3, 4), PI);
```

### Default Export

```javascript
// math.js
export default function multiply(a, b) { return a * b; }

// main.js
import multiply from './math.js';
console.log(multiply(2, 3));
```

### Node.js Modules

- `module.exports` and `require()` for CommonJS modules  
- Modern Node supports ES Modules (`.mjs` or `type: "module"`)
