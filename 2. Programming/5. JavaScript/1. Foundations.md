## Introduction

JavaScript is a **high-level, dynamically typed, interpreted language** widely used for:

- Frontend web development (browsers)  
- Backend development (Node.js)  
- Full-stack applications  
- Serverless and cloud functions  
- Scripting and automation  

It is event-driven, supports functional programming, and has first-class functions, closures, and prototypal inheritance. Learning JavaScript is essential for full-stack AI developers because of its prevalence in web-based dashboards, APIs, and visualization tools.

This tutorial covers the foundations of JavaScript: installation, environment setup, variables, operations, and data structures.

## Installation

### Browsers

- Modern browsers (Chrome, Firefox, Edge, Safari) have built-in JavaScript engines (V8, SpiderMonkey, etc.)  
- You can run JS code in the browser console: `F12` → Console tab

### Node.js (for server-side JS)

1. Download Node.js from <https://nodejs.org>  
2. Verify installation:

```bash
node -v
npm -v
```

### Package Managers

- **npm**: comes with Node.js  
- **yarn**: alternative package manager

## Preparing the Environment

### Editor / IDE

- **VS Code**: widely used, with IntelliSense and debugging  
- **WebStorm**: full-featured IDE  
- **Browser DevTools**: for frontend debugging

### Project Setup

1. Create folder: `mkdir myproject && cd myproject`  
2. Initialize Node.js project: `npm init -y`  
3. Create entry file: `touch index.js`  
4. Run file: `node index.js`  

Example `index.js`:

```javascript
console.log("Hello JavaScript!");
```

## Variables & Basic Types

### Declaring Variables

- `var` → function-scoped (avoid modern use)  
- `let` → block-scoped, mutable  
- `const` → block-scoped, immutable

```javascript
let age = 25;
const name = "Alice";
```

### Data Types

| Type       | Example          | Description                    |
|------------|------------------|--------------------------------|
| Number     | 42, 3.14         | All numbers, integers & floats |
| String     | "Hello"          | Text                           |
| Boolean    | true, false      | Logical values                 |
| Undefined  | undefined        | Variable declared but not set  |
| Null       | null             | Explicitly empty               |
| Symbol     | Symbol("id")     | Unique identifiers             |
| Object     | {}               | Key-value collections          |
| BigInt     | 123n             | Large integers                 |

### Type Checking

```javascript
console.log(typeof 42);      // "number"
console.log(typeof "text");  // "string"
```

## Operations

### Arithmetic Operators

```javascript
let a = 10, b = 3;
console.log(a + b); // 13
console.log(a - b); // 7
console.log(a * b); // 30
console.log(a / b); // 3.3333
console.log(a % b); // 1
console.log(a ** b); // 1000
```

### Comparison Operators

```javascript
a == b
a === b
a != b
a !== b
a > b
a < b
a >= b
a <= b
```

### Logical Operators

```javascript
&&   // AND
||   // OR
!    // NOT
```

### Assignment Operators

```javascript
a += 2
a -= 3
a *= 4
a /= 2
```

## Data Structures (lists, maps, arrays…)

### Arrays

```javascript
let arr = [1, 2, 3];
arr.push(4);
console.log(arr[0]); // 1
```

### Objects (Key-Value Maps)

```javascript
let obj = { name: "Alice", age: 25 };
console.log(obj.name); // "Alice"
obj.age = 26;
```

### Maps (ES6)

```javascript
let map = new Map();
map.set("Alice", 90);
console.log(map.get("Alice")); // 90
```

### Sets (Unique Collections)

```javascript
let set = new Set([1, 2, 3]);
set.add(2); // ignored
console.log(set.has(2)); // true
```

### Strings

- Immutable sequences of characters

```javascript
let str = "Hello";
console.log(str.length);       // 5
console.log(str.toUpperCase()); // "HELLO"
```

### Objects vs Maps vs JSON

- **Object**: simple key-value pairs, string keys only  
- **Map**: keys can be any type, preserves insertion order  
- **JSON**: serialized data, use `JSON.stringify` / `JSON.parse`
