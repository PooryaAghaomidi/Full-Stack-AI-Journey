## Conditions

Conditional statements control program flow based on boolean expressions.

### `if` Statement

```csharp
int x = 10;
if (x > 5) {
    Console.WriteLine("x is greater than 5");
}
```

### `if-else` Statement

```csharp
if (x % 2 == 0) {
    Console.WriteLine("x is even");
} else {
    Console.WriteLine("x is odd");
}
```

### `else if` Ladder

```csharp
if (x > 10) {
    Console.WriteLine("x > 10");
} else if (x > 5) {
    Console.WriteLine("x > 5");
} else {
    Console.WriteLine("x <= 5");
}
```

### Switch Statement

```csharp
switch(x) {
    case 1:
        Console.WriteLine("One"); break;
    case 2:
        Console.WriteLine("Two"); break;
    default:
        Console.WriteLine("Other"); break;
}
```

## Loops

### `for` Loop

```csharp
for(int i = 0; i < 5; i++) {
    Console.WriteLine(i);
}
```

### `while` Loop

```csharp
int i = 0;
while(i < 5) {
    Console.WriteLine(i);
    i++;
}
```

### `do-while` Loop

```csharp
int j = 0;
do {
    Console.WriteLine(j);
    j++;
} while(j < 5);
```

### `break` and `continue`

```csharp
for(int i = 0; i < 10; i++) {
    if(i == 5) break;
    if(i % 2 == 0) continue;
    Console.WriteLine(i);
}
```

## Functions

Functions (methods) encapsulate logic and promote code reuse.

### Basic Method

```csharp
int Add(int a, int b) {
    return a + b;
}
Console.WriteLine(Add(3, 4));
```

### Methods with Multiple Parameters

```csharp
void Greet(string name, int age) {
    Console.WriteLine($"Hello {name}, age {age}");
}
Greet("Alice", 25);
```

### Return Values

- Methods can return values of any type  
- `void` means no return value

### Optional Parameters

```csharp
void Greet(string name = "Guest") {
    Console.WriteLine($"Hello {name}");
}
Greet(); // Hello Guest
```

## Object-Oriented Programming

C# fully supports OOP: **classes, objects, inheritance, interfaces, and polymorphism**.

### Classes and Objects

```csharp
class Person {
    public string Name;
    public int Age;
    
    public void Greet() {
        Console.WriteLine($"Hello, my name is {Name}");
    }
}

Person p = new Person();
p.Name = "Alice";
p.Age = 25;
p.Greet();
```

### Inheritance

```csharp
class Employee : Person {
    public string Position;
    
    public void Work() {
        Console.WriteLine($"{Name} is working as {Position}");
    }
}

Employee e = new Employee();
e.Name = "Bob";
e.Position = "Developer";
e.Greet();
e.Work();
```

### Interfaces

```csharp
interface IWorker {
    void Work();
}

class Developer : IWorker {
    public void Work() {
        Console.WriteLine("Coding...");
    }
}
```

### Encapsulation

- Use `private` for fields, `public` for accessors  
- Properties provide controlled access

```csharp
class Person {
    private int age;
    public int Age {
        get { return age; }
        set { if(value >= 0) age = value; }
    }
}
```

## Modules / Imports

C# uses **namespaces** and **assemblies** to organize code.

### Namespaces

```csharp
using System;
using System.Collections.Generic;

namespace MyApp {
    class Program {
        static void Main() {
            Console.WriteLine("Hello");
        }
    }
}
```

### Assemblies

- Compiled code units (`.dll` or `.exe`)  
- Can reference other assemblies with `Project > Add Reference`  

### Best Practices

- Keep classes organized by namespace  
- Avoid circular dependencies  
- Use `using` statements for clarity and brevity
