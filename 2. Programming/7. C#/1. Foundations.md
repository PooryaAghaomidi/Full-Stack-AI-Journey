## Introduction

C# (C-Sharp) is a **modern, object-oriented, statically-typed language** developed by Microsoft. It is widely used for:

- Backend services (ASP.NET)  
- Desktop applications (Windows Forms, WPF)  
- Game development (Unity)  
- Cloud applications (Azure)  

C# emphasizes **readability, type safety, and performance**, making it an excellent choice for full-stack AI developers who also need to integrate with enterprise applications or cloud services.

This tutorial covers C# foundations: installation, environment setup, variables, operations, and built-in data structures.

---

## Installation

### Windows

- Install **Visual Studio** (Community Edition is free)  
- Select **.NET desktop development** and/or **ASP.NET and web development** workloads  

### macOS / Linux

- Install **Visual Studio Code**  
- Install **.NET SDK** from <https://dotnet.microsoft.com/download>  
- Verify installation:

```bash
dotnet --version
```

---

## Preparing the Environment

### Using Visual Studio

- Create a new project: `Console App`  
- Default template creates `Program.cs`  

### Using VS Code

- Install C# extension (`ms-dotnettools.csharp`)  
- Create project via CLI:

```bash
dotnet new console -n MyApp
cd MyApp
dotnet run
```

### Project Structure

MyApp/
├── Program.cs
├── MyApp.csproj
└── bin/obj (build output)

- `Program.cs` → entry point  
- `.csproj` → project configuration

## Variables & Basic Types

### Declaring Variables

```csharp
int age = 25;
string name = "Alice";
bool isActive = true;
double salary = 3500.50;
char grade = 'A';
```

### Constants

```csharp
const double Pi = 3.14159;
```

### Data Types

- Integer types: `int`, `long`, `short`, `byte`  
- Floating-point: `float`, `double`, `decimal`  
- Boolean: `bool`  
- Character: `char`  
- String: `string`  
- Object: `object` (base type for all types)  

### Type Conversion

```csharp
int x = 10;
double y = (double)x / 3;
string s = x.ToString();
```

## Operations

### Arithmetic Operators

```csharp
int a = 10, b = 3;
Console.WriteLine(a + b); // 13
Console.WriteLine(a - b); // 7
Console.WriteLine(a * b); // 30
Console.WriteLine(a / b); // 3 (integer division)
Console.WriteLine(a % b); // 1
```

### Comparison Operators

```csharp
a == b
a != b
a > b
a < b
a >= b
a <= b
```

### Logical Operators

```csharp
&&   // AND
||   // OR
!    // NOT
```

### Assignment Operators

```csharp
a += 2;
a -= 5;
a *= 3;
a /= 2;
```

## Data Structures (lists, maps, arrays…)

### Arrays (Fixed Size)

```csharp
int[] arr = new int[3] {1, 2, 3};
Console.WriteLine(arr[0]); // 1
```

### Lists (Dynamic Arrays)

```csharp
using System.Collections.Generic;

List<int> list = new List<int>() {1, 2, 3};
list.Add(4);
Console.WriteLine(list[3]); // 4
```

### Dictionaries (Key-Value Pairs)

```csharp
Dictionary<string, int> dict = new Dictionary<string, int>();
dict["Alice"] = 90;
Console.WriteLine(dict["Alice"]); // 90
```

### Strings

- Immutable sequences of characters  
- Useful methods: `.Length`, `.Substring()`, `.ToUpper()`, `.Contains()`, `.Replace()`

### Structs (Custom Data Types)

```csharp
struct Point {
    public int X;
    public int Y;
}

Point p = new Point();
p.X = 10;
p.Y = 20;
```

### Choosing Data Structures

- Arrays → fixed size, fast indexing  
- Lists → dynamic, flexible  
- Dictionaries → key-value mapping  
- Strings → text data  
- Structs → custom value types
