## Error Handling

C# uses **try-catch-finally** for exception handling.

### Basic Example

```csharp
try {
    int result = 10 / 0;
} catch (DivideByZeroException ex) {
    Console.WriteLine("Error: " + ex.Message);
} finally {
    Console.WriteLine("Execution complete");
}
```

### Throwing Exceptions

```csharp
void Divide(int a, int b) {
    if(b == 0) throw new ArgumentException("Cannot divide by zero");
    Console.WriteLine(a / b);
}
```

### Best Practices

- Catch specific exceptions  
- Use `finally` for cleanup  
- Avoid empty catch blocks

## File I/O

C# provides the **System.IO** namespace for file operations.

### Reading Files

```csharp
using System.IO;

string text = File.ReadAllText("input.txt");
Console.WriteLine(text);
```

### Writing Files

```csharp
File.WriteAllText("output.txt", "Hello C#!");
```

### Advanced I/O

- `StreamReader` and `StreamWriter` for line-by-line processing  
- `FileStream` for byte-level operations

## Package Management

### Adding Packages

- Visual Studio: `Manage NuGet Packages`  
- CLI:

```bash
dotnet add package Newtonsoft.Json
```

### Updating / Removing

- `dotnet remove package <package-name>`  
- `dotnet list package` to see installed packages

### Best Practices

- Lock versions in `*.csproj`  
- Avoid unnecessary dependencies  
- Keep packages up-to-date for security

## Concurrency / Async

C# supports **multithreading** and **async programming**.

### Threads

```csharp
using System.Threading;

Thread t = new Thread(() => Console.WriteLine("Hello from thread"));
t.Start();
t.Join();
```

### Task-based Asynchronous Pattern (TAP)

```csharp
using System.Threading.Tasks;

async Task<int> FetchDataAsync() {
    await Task.Delay(1000); // simulate delay
    return 42;
}

int result = await FetchDataAsync();
Console.WriteLine(result);
```

### Async / Await

- Makes asynchronous code look synchronous  
- Prevents blocking the main thread

## Common Gotchas / Tips

- **Null reference exceptions**: always check for null  
- **Off-by-one errors**: careful with loops and array indexes  
- **Dispose objects**: use `using` for streams and database connections  
- **Thread safety**: synchronize shared resources  
- **Floating-point precision**: use `decimal` for money  
- **Immutable strings**: modifying strings creates new instances
