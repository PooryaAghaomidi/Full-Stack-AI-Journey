## Introduction

### What is Python?

Python is a high-level, beginner-friendly programming language known for its clean syntax and large ecosystem. It is widely used in web development, data science, automation, scripting, machine learning, and more. Its goal is to let you focus on *solving problems*, not managing complex syntax.

### GIL

**GIL (Global Interpreter Lock)** is a mutex (lock) used in CPython—the standard implementation of Python—to ensure that only **one thread executes Python bytecode at a time**.  
It prevents multiple native threads from running Python code simultaneously within a single process.

**Why does it exist?**

- CPython’s memory management is **not thread-safe**, so the GIL simplifies memory handling.  
- It avoids the overhead of fine-grained locks around every object.

**Implications:**

- **Multithreading does not speed up CPU-bound tasks** (e.g., heavy computations).  
- **I/O-bound programs** (e.g., networking, file operations) can still benefit from threads because threads often release the GIL during blocking I/O.  
- For true parallel CPU execution, you need **multiprocessing**, **C extensions**, or an alternative interpreter like **PyPy STM** or **Jython**.

### Key Features of Python

Python’s design philosophy emphasizes **readability**, **simplicity**, and **developer productivity**. Some key features include:

- **Clear, readable syntax** using indentation.
- **Interpreted** execution for fast development and debugging.
- **Dynamically typed** variables determined at runtime.
- **Broad standard library** covering networking, math, file I/O, testing, and more.
- **Cross-platform** compatibility (Windows, macOS, Linux, etc.).
- **Extensible and embeddable** through C/C++, Java, Rust, and more.

### Popular Applications of Python

Python is used in many fields, such as:

- **Web development** — Django, Flask, FastAPI  
- **Data science & analytics** — NumPy, pandas, Matplotlib  
- **Machine learning & AI** — TensorFlow, PyTorch, scikit-learn  
- **Automation & scripting** — system tasks, DevOps, workflow automation  
- **Software testing** — pytest, unittest  
- **Scientific computing, networking, cybersecurity, game development**, and more

### Python Implementations

Multiple implementations of Python exist, each with different strengths:

- **CPython** — The official and most widely used implementation (includes the GIL).  
- **PyPy** — A faster JIT-compiled implementation.  
- **Jython** — Runs on the Java Virtual Machine.  
- **IronPython** — Designed for the .NET framework.  
- **MicroPython** — Lightweight version for microcontrollers.

### Python 2 vs. Python 3

Python 3 is the active, modern version of the language:

- **Python 2 reached end-of-life in 2020.**  
- Python 3 includes better Unicode support, cleaner syntax, improved libraries, and significant performance enhancements.  
- Most modern code and libraries fully support Python 3 only.

## Installation

### Windows / macOS / Linux

1. Go to the official website: <https://python.org>  
2. Download the latest stable version (usually Python 3.x).  
3. During installation on Windows, **check “Add Python to PATH”**.

### Verify installation

Open your terminal (Command Prompt, PowerShell, macOS Terminal, Linux shell):

```python
python --version
# or on some systems:
python3 --version
```

You should see something like:

```python
Python 3.12.1
```

## Variables & Basic Types

Python is dynamically typed, meaning you don’t need to declare variable types.  
A variable is created as soon as you assign a value.

### Examples

```python
name = "Alice"          # string
age = 25                # integer
height = 1.72           # float
is_student = True       # boolean
```

### Checking a type

```python
print(type(name))       # <class 'str'>
```

### Reassigning types

Python allows reassigning a variable to a different type:

```python
x = 10
x = "Now I'm a string"
```

## Operations

### Arithmetic

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3  (integer division)
print(a % b)   # 1
print(a ** b)  # 1000 (power)
```

### Comparison

```python
print(5 > 3)   # True
print(5 == 5)  # True
print(5 != 4)  # True
```

### Logical operators

```python
is_raining = False
is_windy = True

print(is_raining and is_windy)  # False
print(is_raining or is_windy)   # True
print(not is_raining)           # True
```

### String operations

```python
greet = "Hello"
name = "Bob"

print(greet + " " + name)    # Hello Bob
print(greet * 3)             # HelloHelloHello
```

## Data Structures

Python includes several built-in data structures that cover most everyday tasks.

---

### **List** (ordered, mutable collection)

```python
numbers = [1, 2, 3, 4]
print(numbers[0])      # 1

numbers.append(5)
print(numbers)         # [1, 2, 3, 4, 5]

numbers[1] = 20
print(numbers)         # [1, 20, 3, 4, 5]
```

---

### **Tuple** (ordered, *immutable* collection)

```python
point = (10, 20)
print(point[0])        # 10

# point[0] = 30  # ❌ Error: tuples cannot be modified
```

---

### **Dictionary** (key–value pairs, similar to “maps”)

```python
person = {
    "name": "Alice",
    "age": 30,
    "city": "London"
}

print(person["name"])              # Alice
person["age"] = 31                 # Modify value
print(person.get("city"))          # London
```

---

### **Set** (unique, unordered values)

```python
items = {1, 2, 3, 3, 3}
print(items)     # {1, 2, 3}  (duplicates removed)

items.add(4)
print(items)     # {1, 2, 3, 4}
```

---

### **Strings as sequences**

Strings behave like immutable lists of characters:

```python
text = "Python"

print(text[0])        # P
print(text[-1])       # n
print(text[1:4])      # yth
```
