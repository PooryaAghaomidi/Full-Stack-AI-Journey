## Conditions

Conditions let your program choose between different actions. Use `if`, `elif`, and `else` to branch based on boolean expressions.

Simple example:

```python
x = 10

if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")
```

Truthiness rules (short): empty containers and `0` are `False`; most other values are `True`.

```python
items = []
if items:
    print("has items")
else:
    print("empty")   # prints "empty"
```

Short-circuit logic — `and` / `or` stop evaluating early:

```python
a = None
b = "fallback"
result = a or b   # "fallback"
```

Use chained comparisons for readability:

```python
n = 5
if 0 <= n < 10:
    print("single digit")
```

## Loops

Loops repeat actions. Python has `for` (iterate over sequences) and `while` (repeat while condition is true).

`for` example — iterate a list:

```python
fruits = ["apple", "banana", "cherry"]
for f in fruits:
    print(f)
```

`range()` is commonly used for numeric loops:

```python
for i in range(5):   # 0,1,2,3,4
    print(i)
```

`while` example:

```python
count = 3
while count > 0:
    print(count)
    count -= 1
```

Control flow inside loops:

```python
for i in range(10):
    if i % 2 == 0:
        continue   # skip even numbers
    if i > 7:
        break      # stop loop early
    print(i)
```

Loop with `else`: runs when loop finishes normally (no `break`):

```python
for n in range(2, 6):
    for d in range(2, n):
        if n % d == 0:
            print(n, "is composite")
            break
    else:
        print(n, "is prime")   # executed when inner loop didn't break
```

## Functions

Functions package logic into reusable units. Define with `def`, call by name, support defaults, keyword args, varargs, and return values.

Basic function:

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))  # Hello, Alice!
```

Default and keyword arguments:

```python
def power(x, exponent=2):
    return x ** exponent

print(power(3))       # 9
print(power(3, 3))    # 27
print(power(x=2, exponent=5))  # 32
```

Variable arguments:

```python
def add_all(*nums):        # positional varargs tuple
    return sum(nums)

def build_dict(**kwargs):  # keyword varargs dict
    return kwargs

print(add_all(1,2,3))            # 6
print(build_dict(a=1, b=2))      # {'a':1, 'b':2}
```

Higher-order functions and lambdas:

```python
def apply_twice(f, x):
    return f(f(x))

print(apply_twice(lambda v: v + 3, 5))  # 11
```

Docstrings and annotations (optional but helpful):

```python
def area(radius: float) -> float:
    """Return area of a circle given radius."""
    import math
    return math.pi * radius * radius
```

Scope basics: variables inside functions are local unless declared `global` or `nonlocal`.

```python
x = 5

def change():
    global x
    x = 10

change()
print(x)   # 10
```

## OOP

Python supports object-oriented programming with classes, instances, inheritance, and special methods (dunder methods).

Simple class and instance:

```python
class Dog:
    def __init__(self, name):
        self.name = name            # instance attribute

    def speak(self):
        return f"{self.name} says woof"

d = Dog("Buddy")
print(d.speak())   # Buddy says woof
```

Inheritance and overriding:

```python
class Animal:
    def speak(self):
        return "..."

class Cat(Animal):
    def speak(self):
        return "meow"

c = Cat()
print(c.speak())   # meow
```

Special methods allow objects to behave like built-ins:

```python
class Vec:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vec(self.x + other.x, self.y + other.y)

    def __repr__(self):
        return f"Vec({self.x}, {self.y})"

v1 = Vec(1, 2)
v2 = Vec(3, 4)
print(v1 + v2)  # Vec(4, 6)
```

Properties for controlled attribute access:

```python
class Person:
    def __init__(self, name):
        self._name = name

    @property
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        if not value:
            raise ValueError("name cannot be empty")
        self._name = value

p = Person("Eva")
print(p.name)    # Eva
p.name = "Lia"
```

Composition vs inheritance: prefer composing objects (holding other objects) when it models the problem better.

## Modules / Imports

Modules help organize code into separate files. A module is any `.py` file. A package is a directory with `__init__.py` (modern Python treats directories without `__init__.py` differently for namespace packages — but a simple `__init__.py` is common).

Create a module `math_utils.py`:

```python
# math_utils.py

def add(a, b):
    return a + b

def mul(a, b):
    return a * b

PI = 3.14159
```

Use it from another file:

```python
# main.py
import math_utils

print(math_utils.add(2, 3))      # 5
print(math_utils.PI)             # 3.14159
```

Import specific names:

```python
from math_utils import add, PI
print(add(1,1))   # 2
print(PI)
```

Alias imports:

```python
import math_utils as mu
print(mu.mul(3,4))   # 12
```

`if __name__ == "__main__"` pattern — run module as script or import safely:

```python
# greet.py
def main():
    print("Running as script")

if __name__ == "__main__":
    main()
```

Package example (file layout):

```python
my_pkg/
    __init__.py      # can be empty or export symbols
    utils.py
    data/
        __init__.py
        loader.py
```

Relative imports inside a package:

```python
# my_pkg/utils.py
from .data.loader import load_data
```

Installing third-party packages and using them (example using `requests`):

```shell
# install (run in shell)
pip install requests
```

```python
# use in code
import requests
resp = requests.get("https://httpbin.org/get")
print(resp.status_code)
```

Quick tips:

- Keep related functions/classes together in a module.
- Small modules are easier to test and reuse.
- Use virtual environments (`venv`) to avoid dependency clashes.
