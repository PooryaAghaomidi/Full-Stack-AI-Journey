## Overview: Object Interaction and Communication

**Behavioral patterns** focus on **how objects interact and communicate**.  
They provide solutions for **managing algorithms, responsibilities, and messaging** between objects.

**Key Points:**

- Reduce **tight coupling between objects**  
- Make complex communication more **flexible and maintainable**  
- Commonly used in **UI frameworks, event systems, and AI workflows**

---

## Observer

**Purpose:** Define a **one-to-many dependency** so that when one object changes state, all dependents are notified automatically.

**Use Cases:**  

- Event-driven programming  
- GUI updates  
- AI model monitoring

**Python Example:**

```python
class Subject:
    def __init__(self):
        self.observers = []
        self._state = None

    def attach(self, observer):
        self.observers.append(observer)

    def set_state(self, state):
        self._state = state
        self.notify()

    def notify(self):
        for observer in self.observers:
            observer.update(self._state)

class Observer:
    def update(self, state):
        print(f"Observer received state: {state}")

# Usage
subject = Subject()
observer1 = Observer()
observer2 = Observer()
subject.attach(observer1)
subject.attach(observer2)
subject.set_state("new state")
```

## Strategy

**Purpose:** Define a **family of algorithms**, encapsulate each one, and make them interchangeable.

**Use Cases:**  

- Sorting strategies  
- AI preprocessing pipelines  
- Dynamic algorithm selection

**Python Example:**

```python
class Strategy:
    def execute(self, data):
        pass

class BubbleSortStrategy(Strategy):
    def execute(self, data):
        return sorted(data)  # Simplified

class QuickSortStrategy(Strategy):
    def execute(self, data):
        return sorted(data)  # Simplified

class Context:
    def __init__(self, strategy: Strategy):
        self.strategy = strategy
    def execute_strategy(self, data):
        return self.strategy.execute(data)

# Usage
context = Context(BubbleSortStrategy())
print(context.execute_strategy([3,1,2]))
```

## Command

**Purpose:** Encapsulate a **request as an object**, allowing parameterization, queuing, and undo operations.

**Use Cases:**  

- Undo/redo operations  
- Task scheduling  
- AI experiment pipelines

**Python Example:**

```python
class Command:
    def execute(self):
        pass

class TurnOnCommand(Command):
    def execute(self):
        print("Device is ON")

class Remote:
    def __init__(self):
        self.commands = []
    def store_command(self, command):
        self.commands.append(command)
    def run(self):
        for command in self.commands:
            command.execute()

# Usage
remote = Remote()
remote.store_command(TurnOnCommand())
remote.run()
```

## State

**Purpose:** Allow an object to **change behavior when its internal state changes**.

**Use Cases:**  

- AI model lifecycle (training, evaluating, deploying)  
- Game character states  

**Python Example:**

```python
class State:
    def handle(self, context):
        pass

class StartState(State):
    def handle(self, context):
        print("Starting")
        context.state = StopState()

class StopState(State):
    def handle(self, context):
        print("Stopping")
        context.state = StartState()

class Context:
    def __init__(self, state):
        self.state = state
    def request(self):
        self.state.handle(self)

# Usage
context = Context(StartState())
context.request()  # Starting
context.request()  # Stopping
```

## Template Method

**Purpose:** Define the **skeleton of an algorithm** in a method, deferring some steps to subclasses.

**Use Cases:**  

- AI training pipelines  
- Data preprocessing steps  
- Standardized workflows with customizable steps

**Python Example:**

```python
class DataPipeline:
    def process(self):
        self.load_data()
        self.transform_data()
        self.save_data()
    def load_data(self): pass
    def transform_data(self): pass
    def save_data(self): pass

class MyPipeline(DataPipeline):
    def load_data(self):
        print("Loading CSV")
    def transform_data(self):
        print("Normalizing data")
    def save_data(self):
        print("Saving output")

# Usage
pipeline = MyPipeline()
pipeline.process()
```

## Iterator

**Purpose:** Provide a way to **access elements of a collection sequentially** without exposing its underlying representation.

**Use Cases:**  

- Iterating datasets  
- Traversing AI model layers  

**Python Example:**

```python
class MyIterator:
    def __init__(self, collection):
        self.collection = collection
        self.index = 0
    def __iter__(self):
        return self
    def __next__(self):
        if self.index < len(self.collection):
            item = self.collection[self.index]
            self.index += 1
            return item
        raise StopIteration

# Usage
for item in MyIterator([1,2,3]):
    print(item)
```

## Mediator

**Purpose:** Define an object that **encapsulates how a set of objects interact**, promoting loose coupling.

**Use Cases:**  

- Chat applications  
- AI component communication  
- GUI control coordination  

**Python Example:**

```python
class Mediator:
    def notify(self, sender, event):
        pass

class ConcreteMediator(Mediator):
    def __init__(self, component1, component2):
        self.component1 = component1
        self.component2 = component2
        component1.mediator = self
        component2.mediator = self
    def notify(self, sender, event):
        if event == "A":
            self.component2.do_b()
        elif event == "B":
            self.component1.do_a()

class Component:
    def __init__(self):
        self.mediator = None

class Component1(Component):
    def do_a(self):
        print("Component1 does A")
        self.mediator.notify(self, "A")

class Component2(Component):
    def do_b(self):
        print("Component2 does B")
        self.mediator.notify(self, "B")

# Usage
c1 = Component1()
c2 = Component2()
mediator = ConcreteMediator(c1, c2)
c1.do_a()
```

## Chain of Responsibility

**Purpose:** Pass a request along a **chain of handlers** until one handles it.

**Use Cases:**  

- Event handling systems  
- AI workflow pipelines  
- Authorization and logging systems

**Python Example:**

```python
class Handler:
    def __init__(self, successor=None):
        self.successor = successor
    def handle(self, request):
        if self.successor:
            self.successor.handle(request)

class ConcreteHandler1(Handler):
    def handle(self, request):
        if request == "A":
            print("Handled by Handler1")
        elif self.successor:
            self.successor.handle(request)

class ConcreteHandler2(Handler):
    def handle(self, request):
        print("Handled by Handler2")

# Usage
h1 = ConcreteHandler1()
h2 = ConcreteHandler2()
h1.successor = h2
h1.handle("A")  # Handled by Handler1
h1.handle("B")  # Handled by Handler2
```
