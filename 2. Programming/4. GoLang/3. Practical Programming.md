## Error Handling

Go uses **error values** instead of exceptions.

### Returning Errors

```go
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("division by zero")
    }
    return a / b, nil
}
```

### Handling Errors

```go
result, err := divide(10, 0)
if err != nil {
    fmt.Println("Error:", err)
} else {
    fmt.Println("Result:", result)
}
```

### Best Practices

- Always check errors  
- Prefer explicit error handling over panics  
- Use `defer` for cleanup after errors

## File I/O

Go provides the **os** and **io/ioutil** packages for file operations.

### Reading Files

```go
import (
    "fmt"
    "io/ioutil"
)

data, err := ioutil.ReadFile("input.txt")
if err != nil {
    fmt.Println("Error:", err)
} else {
    fmt.Println(string(data))
}
```

### Writing Files

```go
import (
    "fmt"
    "io/ioutil"
)

err := ioutil.WriteFile("output.txt", []byte("Hello Go!"), 0644)
if err != nil {
    fmt.Println("Error:", err)
}
```

### Using `os` for Advanced I/O

```go
import (
    "os"
)

file, err := os.Open("input.txt")
if err != nil {
    fmt.Println("Error:", err)
    return
}
defer file.Close()
```

## Concurrency / Async

Go has **goroutines** and **channels** for concurrency.

### Goroutines

```go
go func() {
    fmt.Println("Hello from goroutine")
}()
```

### Channels

```go
ch := make(chan int)
go func() { ch <- 42 }()
val := <-ch
fmt.Println(val) // 42
```

### Buffered Channels

```go
ch := make(chan int, 2)
ch <- 1
ch <- 2
fmt.Println(<-ch)
fmt.Println(<-ch)
```

### Select Statement

```go
select {
case msg := <-ch1:
    fmt.Println(msg)
case msg := <-ch2:
    fmt.Println(msg)
default:
    fmt.Println("No messages")
}
```

### Best Practices

- Avoid shared memory; prefer channels  
- Use `sync` package for mutexes if needed  
- Keep goroutines short-lived or controlled with context

## Debugging Basics

### Tools

- `dlv` (Delve) — Go debugger  
- IDEs like VS Code and GoLand have integrated debugging  
- Print debugging (`fmt.Println`) for quick checks

### Delve Example

```bash
dlv debug main.go
(dlv) break main.main
(dlv) continue
(dlv) print variable
(dlv) next
```

### Tips

- Compile with `-gcflags "all=-N -l"` to disable optimizations for better debugging  
- Use `panic` and `recover` to catch unexpected errors in development

## Common Gotchas / Tips

- **Nil slices/maps**: initialize before use  
- **Pointer vs value receivers**: know which to use in methods  
- **Goroutine leaks**: always ensure they terminate  
- **Error handling**: never ignore errors  
- **Defer order**: executes in LIFO (last-in, first-out)  
- **Integer division**: converts to integer automatically  
- **Concurrent map access**: use sync.Map or mutex to prevent race conditions  
- **Avoid global state**: prefer passing dependencies explicitly
