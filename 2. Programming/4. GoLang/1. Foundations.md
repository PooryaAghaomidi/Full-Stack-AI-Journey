## Introduction

Go (or Golang) is a statically typed, compiled language created by Google for **simplicity, efficiency, and scalability**. It is especially popular for:

- Backend services and APIs  
- Microservices  
- Cloud and networking applications  
- Distributed systems  

Go’s design focuses on **readability, fast compilation, garbage collection, and concurrency support** through goroutines and channels. Learning Go provides you with a strong foundation for writing clean, efficient, and concurrent software.

This tutorial covers Go's foundations: installation, environment setup, variables, operations, and built-in data structures.

## Installation

### Windows / macOS / Linux

1. Download the Go installer from the official site: <https://golang.org/dl/>  
2. Follow the platform-specific instructions.

### Verify Installation

```bash
go version
# Output example: go version go1.21 windows/amd64
```

### Set GOPATH (Optional)

- Default workspace directory for Go projects  
- Usually `$HOME/go`  
- Environment variable `GOPATH` can be set manually if needed.

## Preparing the Environment

### Editor / IDE

- **VS Code**: official Go extension (`golang.Go`)  
- **GoLand**: JetBrains IDE with full Go support  
- **Lite editors**: vim, emacs with Go plugins

### Workspace Structure

Typical Go project layout:

```text
project/
├── go.mod
├── main.go
└── pkg/
```

- `go.mod` defines module and dependencies  
- `main.go` contains the program entry point  
- `pkg/` for packages

### Create a Module

```bash
go mod init myproject
```

### Run Your First Program

Create `main.go`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello Go!")
}
```

Run:

```bash
go run main.go
```

## Variables & Basic Types

Go is statically typed but supports type inference.

### Declaring Variables

```go
var age int = 25
var name string = "Alice"
var active bool = true
```

### Short Declaration

```go
age := 25        // int
name := "Alice"  // string
```

### Constants

```go
const Pi = 3.14159
const DaysInWeek int = 7
```

### Basic Types

- Integers: `int`, `int8`, `int16`, `int32`, `int64`  
- Unsigned integers: `uint`, `uint8`, `byte`  
- Floating-point: `float32`, `float64`  
- Boolean: `bool`  
- String: `string`  
- Complex: `complex64`, `complex128`  
- Rune (Unicode code point): `rune`  

### Type Conversion

```go
var x int = 10
var y float64 = float64(x) / 3.0
```

## Operations

### Arithmetic Operators

```go
a, b := 10, 3
fmt.Println(a + b)  // 13
fmt.Println(a - b)  // 7
fmt.Println(a * b)  // 30
fmt.Println(a / b)  // 3 (integer division)
fmt.Println(a % b)  // 1
```

### Comparison Operators

```go
a == b
a != b
a > b
a < b
a >= b
a <= b
```

### Logical Operators

```go
&&   // AND
||   // OR
!    // NOT
```

### Assignment Operators

```go
a += 2
a -= 5
a *= 10
a /= 3
```

## Data Structures (lists, maps, arrays…)

Go provides simple and efficient built-in data structures.

### Arrays (Fixed Size)

```go
var arr [3]int = [3]int{1, 2, 3}
```

### Slices (Dynamic Arrays)

```go
s := []int{1, 2, 3}
s = append(s, 4)
fmt.Println(s) // [1 2 3 4]
```

### Maps (Key-Value Pairs)

```go
m := map[string]int{"Alice": 90, "Bob": 85}
m["Charlie"] = 95
fmt.Println(m["Alice"]) // 90
```

### Strings

- Immutable sequences of bytes
- Can be iterated over runes (Unicode code points)

```go
s := "Hello"
for _, c := range s {
    fmt.Println(string(c))
}
```

### Structs (Composite Data Types)

```go
type Person struct {
    Name string
    Age  int
}

p := Person{Name: "Alice", Age: 25}
fmt.Println(p.Name)
```

### Pointers

- Store memory address of a variable  
- `&` operator gives address, `*` dereferences

```go
x := 10
p := &x
*p = 20
fmt.Println(x) // 20
```

### Choosing Data Structures

- Arrays → fixed size, fast indexing  
- Slices → dynamic, most common  
- Maps → key-value lookup  
- Structs → custom complex types
