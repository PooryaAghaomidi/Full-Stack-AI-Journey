## Conditions

Conditional statements control program flow based on boolean expressions.

### `if` Statement

```go
x := 10
if x > 5 {
    fmt.Println("x is greater than 5")
}
```

### `if-else` Statement

```go
if x%2 == 0 {
    fmt.Println("x is even")
} else {
    fmt.Println("x is odd")
}
```

### `else if` Ladder

```go
if x > 10 {
    fmt.Println("x > 10")
} else if x > 5 {
    fmt.Println("x > 5")
} else {
    fmt.Println("x <= 5")
}
```

### Short Statement in `if`

Go allows initializing variables inside the `if` statement:

```go
if y := x * 2; y > 10 {
    fmt.Println("y is large")
}
```

## Loops

Go has only one loop type: `for`. It is versatile and can replace while and do-while loops.

### Standard For Loop

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

### While-Style Loop

```go
i := 0
for i < 5 {
    fmt.Println(i)
    i++
}
```

### Infinite Loop

```go
for {
    // loop forever
    break // exit condition
}
```

### `break` and `continue`

- `break` exits the loop  
- `continue` skips to the next iteration

```go
for i := 0; i < 10; i++ {
    if i == 5 { break }
    if i%2 == 0 { continue }
    fmt.Println(i)
}
```

## Functions

Functions encapsulate logic and promote code reuse.

### Basic Function

```go
func add(a int, b int) int {
    return a + b
}

func main() {
    fmt.Println(add(3, 4))
}
```

### Multiple Return Values

```go
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("division by zero")
    }
    return a / b, nil
}
```

### Variadic Functions

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

### Named Return Values

```go
func rectangle(width, height int) (area, perimeter int) {
    area = width * height
    perimeter = 2 * (width + height)
    return
}
```

### Scope

- Local variables: declared inside a function, visible only there  
- Package-level variables: declared outside functions, visible throughout the package

## Object-Oriented Programming

Go does not have classes but supports **OOP concepts** via **structs and interfaces**.

### Structs

```go
type Person struct {
    Name string
    Age  int
}

func main() {
    p := Person{Name: "Alice", Age: 25}
    fmt.Println(p.Name)
}
```

### Methods

Attach functions to structs:

```go
func (p Person) Greet() {
    fmt.Println("Hello, my name is", p.Name)
}
```

### Pointer Receivers

Modify struct fields:

```go
func (p *Person) HaveBirthday() {
    p.Age++
}
```

### Interfaces

Define behavior contracts:

```go
type Greeter interface {
    Greet()
}

func SayHello(g Greeter) {
    g.Greet()
}
```

### Composition Over Inheritance

Go encourages **composition** instead of inheritance:

```go
type Employee struct {
    Person
    Position string
}
```

## Modules / Imports

Go uses **packages** and **modules** for modularity.

### Standard Library

```go
import (
    "fmt"
    "math"
)
```

### Custom Packages

Project layout:

```text
project/
├── go.mod
├── main.go
└── utils/
└── util.go
```

`util.go`:

```go
package utils

func Add(a, b int) int {
    return a + b
}
```

`main.go`:

```go
package main

import (
    "fmt"
    "project/utils"
)

func main() {
    fmt.Println(utils.Add(3, 4))
}
```

### Modules

Initialize module:

```bash
go mod init project
```

- `go.mod` keeps track of module name and dependencies  
- `go get` adds external packages  
- `go build` compiles the project  

### Best Practices

- Keep packages small and focused  
- Avoid circular dependencies  
- Name packages clearly, usually singular nouns
