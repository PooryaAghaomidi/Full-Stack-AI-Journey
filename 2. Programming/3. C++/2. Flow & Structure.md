## Conditions

Conditional statements allow your program to **branch** based on boolean logic.

### `if` Statement

```cpp
int x = 10;
if (x > 5) {
    std::cout << "x is greater than 5\n";
}
```

### `if-else` Statement

```cpp
if (x % 2 == 0) {
    std::cout << "x is even\n";
} else {
    std::cout << "x is odd\n";
}
```

### `else if` Ladder

```cpp
if (x > 10) {
    std::cout << "x > 10\n";
} else if (x > 5) {
    std::cout << "x > 5\n";
} else {
    std::cout << "x <= 5\n";
}
```

### Ternary Operator

Compact conditional assignment:

```cpp
std::string result = (x % 2 == 0) ? "even" : "odd";
std::cout << result << "\n";
```

## Loops

Loops let you **repeat code** efficiently.

### `for` Loop

```cpp
for (int i = 0; i < 5; i++) {
    std::cout << i << "\n";
}
```

- Initialization: `int i = 0`
- Condition: `i < 5`
- Increment: `i++`

### `while` Loop

```cpp
int i = 0;
while (i < 5) {
    std::cout << i << "\n";
    i++;
}
```

### `do-while` Loop

Executes at least once:

```cpp
int i = 0;
do {
    std::cout << i << "\n";
    i++;
} while (i < 5);
```

### `break` and `continue`

- `break` exits the loop immediately  
- `continue` skips to the next iteration

```cpp
for (int i = 0; i < 10; i++) {
    if (i == 5) break;
    if (i % 2 == 0) continue;
    std::cout << i << "\n";
}
```

## Functions

Functions encapsulate logic, promote reuse, and improve readability.

### Basic Function

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

int main() {
    std::cout << add(3, 4) << "\n";
}
```

### Function Parameters & Return Values

- Pass by value (default) — copies argument  
- Pass by reference (`&`) — modifies original  
- Pass by const reference (`const &`) — efficient read-only

```cpp
void increment(int &x) {
    x++;
}

int main() {
    int a = 5;
    increment(a);
    std::cout << a; // 6
}
```

### Function Overloading

Same function name, different parameter types:

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

### Default Parameters

```cpp
int power(int base, int exponent = 2) {
    int result = 1;
    for (int i = 0; i < exponent; i++) result *= base;
    return result;
}
```

## Object-Oriented Programming

OOP allows modeling **real-world entities** in code.

### Class and Object

```cpp
class Person {
public:
    std::string name;
    int age;

    void greet() {
        std::cout << "Hello, my name is " << name << "\n";
    }
};

int main() {
    Person p;
    p.name = "Alice";
    p.age = 25;
    p.greet();
}
```

### Encapsulation

- Keep internal state private  
- Expose public methods for controlled access

```cpp
class Counter {
private:
    int value;
public:
    Counter() : value(0) {}
    void increment() { value++; }
    int getValue() const { return value; }
};
```

### Constructor & Destructor

- **Constructor**: called on object creation  
- **Destructor**: called on object destruction

```cpp
class Resource {
public:
    Resource() { std::cout << "Allocated\n"; }
    ~Resource() { std::cout << "Released\n"; }
};
```

### Inheritance

```cpp
class Animal {
public:
    void eat() { std::cout << "Eating\n"; }
};

class Dog : public Animal {
public:
    void bark() { std::cout << "Woof\n"; }
};

int main() {
    Dog d;
    d.eat();
    d.bark();
}
```

### Polymorphism (Virtual Functions)

```cpp
class Shape {
public:
    virtual void draw() { std::cout << "Shape\n"; }
};

class Circle : public Shape {
public:
    void draw() override { std::cout << "Circle\n"; }
};

int main() {
    Shape* s = new Circle();
    s->draw(); // Circle
    delete s;
}
```

### Access Specifiers

- `public` — accessible anywhere  
- `private` — accessible only inside the class  
- `protected` — accessible in class and subclasses

## Modules / Imports

C++ uses **headers and source files** for modularity.

### Include Header Files

- Standard library headers:

```cpp
#include <iostream>
#include <vector>
#include <string>
```

- Custom headers:

```cpp
#include "myheader.h"
```

### Namespaces

Avoid name collisions and organize code:

```cpp
#include <iostream>
namespace mylib {
    void greet() { std::cout << "Hi\n"; }
}

int main() {
    mylib::greet();
}
```

### Header Guards / `#pragma once`

Prevent multiple inclusions:

```cpp
#ifndef MYHEADER_H
#define MYHEADER_H

void myFunc();

#endif
```

Or modern alternative:

```cpp
#pragma once
void myFunc();
```

### Separate Compilation

- Header files (`.h` / `.hpp`) contain declarations  
- Source files (`.cpp`) contain definitions  
- Compile and link together:

```bash
g++ main.cpp mymodule.cpp -o program
```

### Best Practices

- Keep interfaces (headers) minimal  
- Avoid heavy dependencies in headers  
- Use forward declarations when possible
