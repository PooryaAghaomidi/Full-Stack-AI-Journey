## Introduction

C++ is one of the most powerful and influential programming languages ever created. It balances **high performance**, **low-level memory control**, and **high-level abstractions**, making it ideal for:

- Operating systems  
- Game engines  
- High-performance computing  
- AI infrastructure (PyTorch is written in C++)  
- Embedded systems  
- Real-time and latency-critical systems  

Learning C++ gives you an understanding of how computers *really* work: memory, pointers, compilation, optimizations, and CPU-level behavior. This knowledge will make you a stronger AI developer — even if you use Python daily.

This tutorial covers the foundations you must understand before moving into modern C++ (classes, templates, RAII, smart pointers, STL, multithreading, etc.).

## Installation

To write and compile C++ code, you need:

### A C++ Compiler

Common compilers:

- **GCC** (Linux / macOS / Windows via MinGW or WSL)
- **Clang** (macOS / Linux / Windows via LLVM)
- **MSVC** (Windows Visual Studio compiler)

### Recommended Installations by System

### **Windows**

1. **Install MSYS2** (recommended for beginners)
   - Includes GCC (mingw-w64), package manager, Unix tools  
   - <https://www.msys2.org/>

2. Update and install GCC:

   ```bash
   pacman -Syu
   pacman -S mingw-w64-x86_64-gcc
   ```

3. Or install **Visual Studio** with the “Desktop development with C++” workload.

### **Linux**

You likely already have GCC. If not:

```bash
sudo apt update
sudo apt install build-essential
```

### **macOS**

Install Xcode command line tools:

```bash
xcode-select --install
```

Or install LLVM:

```bash
brew install llvm
```

### Test the installation

Create `main.cpp`:

```cpp
#include <iostream>
int main() {
    std::cout << "Hello C++\n";
}
```

Compile:

```bash
g++ main.cpp -o main
./main
```

## Preparing the Environment

To work productively with C++, you need:

### An Editor or IDE

Recommended:

- **VS Code** + C++ extensions  
- **CLion** (JetBrains, excellent for CMake projects)  
- **Visual Studio** (best for Windows/MSVC)  

### Build Systems

Modern C++ projects use:

- **CMake** (industry standard)
- Makefiles (simple small projects)
- MSBuild (Visual Studio)

Install CMake:

```bash
sudo apt install cmake          # Linux
brew install cmake              # macOS
```

### Running Your First Project

Folder structure:

```text
project/
├── CMakeLists.txt
└── main.cpp
```

```cmake
cmake_minimum_required(VERSION 3.10)
project(MyProject)
add_executable(main main.cpp)
```

Build:

```bash
mkdir build && cd build
cmake ..
make
./main
```

## Variables & Basic Types

C++ is a **statically typed**, **compiled** language. Every variable has a type known at compile time.

### Primitive Types

| Type | Example | Description |
|------|---------|-------------|
| `int` | 10 | Integer |
| `double` | 3.14 | Floating-point |
| `char` | 'A' | Single character |
| `bool` | true/false | Boolean |
| `float` | 1.23f | Lower precision float |
| `long`, `long long` | large integers | Larger integers |

### Declaring Variables

```cpp
int age = 25;
double pi = 3.14159;
char grade = 'A';
bool done = false;
```

### Constants

```cpp
const int DAYS = 7;
constexpr double PI = 3.14159;
```

- `const` → cannot change after initialization  
- `constexpr` → evaluated at compile time (faster, safer)

### Auto Type Deduction

```cpp
auto x = 42;       // int
auto y = 3.14;     // double
auto s = "text";   // const char*
```

### Input/Output

```cpp
#include <iostream>

int main() {
    int x;
    std::cin >> x;            // input
    std::cout << x << "\n";   // output
}
```

## Operations

### Arithmetic Operators

```cpp
int a = 10, b = 3;
int c = a + b;     // 13
int d = a - b;     // 7
int e = a * b;     // 30
int f = a / b;     // 3 (integer division)
int g = a % b;     // 1
```

### Comparison Operators

```cpp
a == b
a != b
a > b
a < b
a >= b
a <= b
```

### Logical Operators

```cpp
&&   // AND
||   // OR
!    // NOT
```

### Assignment Operators

```cpp
a += 2;
a -= 5;
a *= 10;
a /= 3;
```

### Increment & Decrement

```cpp
a++;   // post-increment
++a;   // pre-increment
```

## Data Structures (lists, maps, arrays…)

C++ provides powerful data structures through the **STL (Standard Template Library)**.

### Arrays (Fixed Size)

```cpp
int arr[3] = {1, 2, 3};
```

### `std::vector` — Dynamic Array (Most Used)

```cpp
#include <vector>

std::vector<int> v = {1, 2, 3};
v.push_back(4);
v[0] = 10;
```

### `std::string`

```cpp
#include <string>

std::string msg = "Hello";
msg += " World";
```

### `std::pair` and `std::tuple`

```cpp
std::pair<int, int> p = {1, 2};
auto [x, y] = p;
```

### `std::map` — Ordered Map (balanced BST)

```cpp
#include <map>

std::map<std::string, int> m;
m["Alice"] = 90;
m["Bob"] = 85;
```

### `std::unordered_map` — Hash Map

```cpp
#include <unordered_map>

std::unordered_map<std::string, int> scores;
scores["John"] = 100;
```

### `std::list` — Doubly Linked List

```cpp
#include <list>

std::list<int> lst = {1, 2, 3};
lst.push_back(4);
lst.push_front(0);
```

### `std::set` — Sorted Unique Elements

```cpp
#include <set>

std::set<int> s = {3, 1, 2, 4};
```

### `std::unordered_set` — Hash Set

```cpp
#include <unordered_set>

std::unordered_set<int> s = {1, 2, 3};
```

### Choosing the Right Structure

| Need | Use |
|------|-----|
| Fast lookups | `unordered_map` |
| Sorted keys | `map` |
| Dynamic array | `vector` |
| Linked list | `list` |
| Unique sorted elements | `set` |
| Very fast insert/erase | `unordered_set/map` |
