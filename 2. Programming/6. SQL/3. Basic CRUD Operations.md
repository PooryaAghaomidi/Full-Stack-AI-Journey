## Introduction

CRUD stands for **Create, Read, Update, Delete** — the four fundamental operations for interacting with databases.

This tutorial covers:

- Retrieving data with `SELECT`  
- Filtering and sorting results  
- Adding new records with `INSERT`  
- Modifying existing data with `UPDATE`  
- Removing data with `DELETE`  

By mastering CRUD operations, you can **perform essential database tasks and manipulate data for real-world projects**.

---

## SELECT Statements

The `SELECT` statement is used to **retrieve data from one or more tables**.

### Basic SELECT

```sql
SELECT column1, column2
FROM employees;
```

- `*` selects all columns:

```sql
SELECT * FROM employees;
```

### Selecting Distinct Values

```sql
SELECT DISTINCT department FROM employees;
```

### Limiting Results

- MySQL / PostgreSQL:

```sql
SELECT * FROM employees LIMIT 5;
```

- SQL Server:

```sql
SELECT TOP 5 * FROM employees;
```

## Filtering Data: WHERE Clause

`WHERE` filters rows based on conditions.

### Comparison Operators

- `=` Equal  
- `!=` or `<>` Not equal  
- `>` Greater than  
- `<` Less than  
- `>=` Greater or equal  
- `<=` Less or equal  

```sql
SELECT * FROM employees
WHERE age > 25;
```

### Logical Operators

- `AND`, `OR`, `NOT`

```sql
SELECT * FROM employees
WHERE age > 25 AND department = 'IT';
```

### Pattern Matching

- `LIKE` with `%` (any characters) and `_` (single character)

```sql
SELECT * FROM employees
WHERE name LIKE 'A%';  -- Names starting with A
```

### NULL Values

- `IS NULL` and `IS NOT NULL`

```sql
SELECT * FROM employees
WHERE phone IS NULL;
```

## Sorting: ORDER BY

`ORDER BY` sorts the results.

- Default: ascending (`ASC`)  
- Descending: `DESC`  

```sql
SELECT * FROM employees
ORDER BY salary DESC;
```

- Multiple columns:

```sql
SELECT * FROM employees
ORDER BY department ASC, salary DESC;
```

## Inserting Data: INSERT

Add new records to a table.

### Basic INSERT

```sql
INSERT INTO employees (id, name, department, age, salary)
VALUES (4, 'David', 'Finance', 29, 58000);
```

### Insert Multiple Rows

```sql
INSERT INTO employees (id, name, department, age, salary)
VALUES 
(5, 'Eva', 'IT', 32, 62000),
(6, 'Frank', 'HR', 26, 51000);
```

### Insert with Default Values

- Columns with defaults can be omitted

```sql
INSERT INTO employees (name, department) VALUES ('Grace', 'Marketing');
```

---

## Updating Data: UPDATE

Modify existing records.

### Basic UPDATE

```sql
UPDATE employees
SET salary = 65000
WHERE name = 'Bob';
```

### Update Multiple Columns

```sql
UPDATE employees
SET department = 'Finance', salary = 60000
WHERE id = 3;
```

### Important Notes

- Always use `WHERE` to avoid updating all rows  
- Use transactions (`BEGIN TRANSACTION` / `ROLLBACK`) when making bulk updates

---

## Deleting Data: DELETE

Remove rows from a table.

### Basic DELETE

```sql
DELETE FROM employees
WHERE name = 'David';
```

### Delete All Rows

- Warning: removes all data in the table

```sql
DELETE FROM employees;
```

- Alternative (drop table):

```sql
DROP TABLE employees;
```

### Safety Tips

- Always use `WHERE` clause  
- Consider `TRUNCATE TABLE` for fast deletion (resets auto-increment counters)
