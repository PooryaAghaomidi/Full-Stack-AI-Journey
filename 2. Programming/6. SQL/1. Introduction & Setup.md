## What is SQL?

SQL (**Structured Query Language**) is a standardized programming language used to **manage and manipulate relational databases**. It allows you to:

- Store, retrieve, and update data  
- Define and modify database structure  
- Control access and permissions  
- Perform complex queries and aggregations  

### Key Features

- Declarative language: You specify *what* you want, not *how* to do it  
- Works with relational databases (tables, rows, columns)  
- Supports ACID properties (Atomicity, Consistency, Isolation, Durability) for reliable transactions  

Example of a simple SQL query:

```sql
SELECT first_name, last_name
FROM users
WHERE age > 18
ORDER BY last_name;
```

This query retrieves all users older than 18 and orders them by their last name.

## Relational Databases vs NoSQL

### Relational Databases (RDBMS)

- Store data in **tables** with predefined schemas  
- Use SQL for querying  
- Examples: MySQL, PostgreSQL, SQLite, Microsoft SQL Server  
- Advantages:  
  - Strong consistency  
  - Structured data  
  - Powerful querying capabilities (joins, aggregations)  

### NoSQL Databases

- Store data in **document, key-value, column, or graph formats**  
- Flexible schema  
- Examples: MongoDB (document), Redis (key-value), Cassandra (column), Neo4j (graph)  
- Advantages:  
  - High scalability  
  - Handles unstructured data  
  - Good for distributed systems  

**Summary:** Use **SQL** for structured data and strong consistency; use **NoSQL** for flexible schemas and large-scale distributed data.

## Installing & Setting Up a SQL Environment

### MySQL

1. Download: <https://dev.mysql.com/downloads/>  
2. Install MySQL Server  
3. Verify installation:

```bash
mysql --version
```

4. Start MySQL server:

- Windows: MySQL Workbench or services panel  
- Linux/macOS: `sudo systemctl start mysql`

### PostgreSQL

1. Download: <https://www.postgresql.org/download/>  
2. Install PostgreSQL and pgAdmin (optional GUI)  
3. Verify installation:

```bash
psql --version
```

4. Start PostgreSQL service:

```bash
sudo systemctl start postgresql
```

### SQLite

- Lightweight, file-based SQL database  
- No server required  
- Install via:

```bash
sudo apt install sqlite3   # Linux
brew install sqlite        # macOS
```

- Verify:

```bash
sqlite3 --version
```

## Tools for Working with SQL

### GUI Tools

- **MySQL Workbench** → MySQL visual editor  
- **pgAdmin** → PostgreSQL management  
- **DBeaver** → Universal SQL GUI  
- Advantages:  
  - Easy visualization of tables  
  - Query building and debugging  
  - Export/import data  

### CLI Tools

- **mysql** → MySQL command line  
- **psql** → PostgreSQL command line  
- Advantages:  
  - Lightweight and fast  
  - Ideal for scripting  
  - Full control of SQL commands  

**Tip:** For beginners, start with GUI tools, but learn CLI for automation and real-world projects.

## Connecting SQL to Programming Languages

SQL can be accessed programmatically via **drivers** or **ORMs**.

### Python

- **Libraries:** `mysql-connector-python`, `psycopg2` (PostgreSQL), `sqlite3`  
- Example (SQLite):

```python
import sqlite3

conn = sqlite3.connect('example.db')
cursor = conn.cursor()

cursor.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)")
cursor.execute("INSERT INTO users (name, age) VALUES (?, ?)", ("Alice", 25))
conn.commit()

cursor.execute("SELECT * FROM users")
print(cursor.fetchall())

conn.close()
```

### C #

- **Libraries:** `System.Data.SqlClient`, `Npgsql` (PostgreSQL)  
- Example:

```csharp
using System.Data.SqlClient;

string connectionString = "Server=localhost;Database=TestDB;User Id=sa;Password=your_password;";
using(SqlConnection conn = new SqlConnection(connectionString)) {
    conn.Open();
    SqlCommand cmd = new SqlCommand("SELECT * FROM users", conn);
    SqlDataReader reader = cmd.ExecuteReader();
    while(reader.Read()) {
        Console.WriteLine(reader["name"]);
    }
}
```

### Node.js

- **Libraries:** `mysql2`, `pg`  
- Example:

```javascript
const mysql = require('mysql2');
const connection = mysql.createConnection({
  host: 'localhost',
  user: 'root',
  database: 'testdb'
});

connection.query('SELECT * FROM users', (err, results) => {
  if(err) throw err;
  console.log(results);
});
connection.end();
```
