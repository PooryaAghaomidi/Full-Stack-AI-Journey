## Introduction

Advanced SQL queries allow you to **analyze, combine, and summarize data** efficiently. This tutorial covers:

- Aggregations for numerical insights  
- Grouping and filtering grouped data  
- Combining data from multiple tables using joins  
- Writing subqueries and nested queries  
- Using Common Table Expressions (CTEs)  
- Window functions for row-level analytics  

These are essential for real-world projects, especially for **reporting, analytics, and AI feature engineering**.

---

## Aggregate Functions

Aggregate functions perform calculations on multiple rows.

| Function | Description |
|----------|-------------|
| `COUNT()` | Number of rows |
| `SUM()`   | Sum of numeric values |
| `AVG()`   | Average of numeric values |
| `MIN()`   | Minimum value |
| `MAX()`   | Maximum value |

### Example

```sql
SELECT COUNT(*) AS total_employees,
       AVG(salary) AS avg_salary,
       MIN(age) AS youngest,
       MAX(age) AS oldest
FROM employees;
```

## Grouping: GROUP BY and HAVING

`GROUP BY` aggregates rows based on one or more columns.  
`HAVING` filters groups (like `WHERE` for aggregated data).

### Example: Employees per Department

```sql
SELECT department, COUNT(*) AS num_employees, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;
```

### Filtering Groups with HAVING

```sql
SELECT department, COUNT(*) AS num_employees
FROM employees
GROUP BY department
HAVING COUNT(*) > 2;
```

## Joins

Joins combine rows from multiple tables based on a related column.

### INNER JOIN

Returns rows with matching values in both tables.

```sql
SELECT e.name, d.name AS department_name
FROM employees e
INNER JOIN departments d
ON e.department_id = d.id;
```

### LEFT JOIN

Returns all rows from the **left table**, matched rows from the right table, NULL if no match.

```sql
SELECT e.name, d.name AS department_name
FROM employees e
LEFT JOIN departments d
ON e.department_id = d.id;
```

### RIGHT JOIN

Returns all rows from the **right table**, matched rows from the left table, NULL if no match.

```sql
SELECT e.name, d.name AS department_name
FROM employees e
RIGHT JOIN departments d
ON e.department_id = d.id;
```

### FULL OUTER JOIN

Returns **all rows from both tables**, with NULLs for unmatched rows.

```sql
SELECT e.name, d.name AS department_name
FROM employees e
FULL OUTER JOIN departments d
ON e.department_id = d.id;
```

### Self-joins

Join a table with itself for hierarchical or comparative analysis.

```sql
SELECT e1.name AS employee, e2.name AS manager
FROM employees e1
LEFT JOIN employees e2
ON e1.manager_id = e2.id;
```

## Subqueries and Nested Queries

A subquery is a **query within a query**, used for filtering, aggregation, or calculations.

### Example: Employees with Above Average Salary

```sql
SELECT name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
```

### Correlated Subqueries

- Refer to outer query row-by-row

```sql
SELECT e1.name, e1.salary
FROM employees e1
WHERE e1.salary > (SELECT AVG(e2.salary) FROM employees e2 WHERE e2.department_id = e1.department_id);
```

## Common Table Expressions (CTEs)

CTEs improve readability and allow **recursive or multi-step queries**.

### Basic CTE

```sql
WITH DepartmentSalary AS (
    SELECT department_id, AVG(salary) AS avg_salary
    FROM employees
    GROUP BY department_id
)
SELECT d.name, ds.avg_salary
FROM departments d
JOIN DepartmentSalary ds ON d.id = ds.department_id;
```

### Recursive CTE

- Useful for hierarchical data

```sql
WITH RECURSIVE EmployeeHierarchy AS (
    SELECT id, name, manager_id
    FROM employees
    WHERE manager_id IS NULL
    UNION ALL
    SELECT e.id, e.name, e.manager_id
    FROM employees e
    INNER JOIN EmployeeHierarchy eh ON e.manager_id = eh.id
)
SELECT * FROM EmployeeHierarchy;
```

## Window Functions

Window functions perform calculations across a **subset of rows** without collapsing them into a single output row.

| Function | Description |
|----------|-------------|
| `ROW_NUMBER()` | Assigns a unique number per row |
| `RANK()`       | Assigns rank with gaps |
| `DENSE_RANK()` | Assigns rank without gaps |
| `LEAD()`       | Access next row value |
| `LAG()`        | Access previous row value |

### Example: Ranking Employees by Salary in Department

```sql
SELECT name, department_id, salary,
       RANK() OVER(PARTITION BY department_id ORDER BY salary DESC) AS salary_rank
FROM employees;
```

### Example: Previous and Next Salary

```sql
SELECT name, salary,
       LAG(salary) OVER(ORDER BY salary) AS previous_salary,
       LEAD(salary) OVER(ORDER BY salary) AS next_salary
FROM employees;
```
