## Introduction

Views, stored procedures, functions, and triggers allow you to **encapsulate, reuse, and automate SQL logic**, making your database more efficient and maintainable. This tutorial covers:

- Creating and using **views**  
- Writing **stored procedures** for repetitive tasks  
- Defining **user-defined functions**  
- Automating actions with **triggers**  

Mastering these tools enables developers to **create advanced, production-ready database systems**.

---

## Creating and Using Views

### What is a View?

A **view** is a **virtual table** based on the result of a `SELECT` query. Views **simplify complex queries**, provide abstraction, and enhance security.

### Creating a View

```sql
CREATE VIEW employee_summary AS
SELECT e.name, e.salary, d.name AS department
FROM employees e
JOIN departments d ON e.department_id = d.id;
```

### Using a View

```sql
SELECT * FROM employee_summary WHERE salary > 50000;
```

### Updating a View

- Some views are **updatable**, allowing `INSERT`, `UPDATE`, `DELETE` directly  
- Others are read-only

## Stored Procedures and Parameterized Queries

### What is a Stored Procedure?

- Stored procedures are **predefined SQL scripts** stored in the database  
- Can accept **parameters**  
- Useful for **repetitive operations** and **complex logic**

### Creating a Stored Procedure

```sql
-- MySQL Example
DELIMITER //

CREATE PROCEDURE GetEmployeesByDepartment(IN dept_id INT)
BEGIN
    SELECT * FROM employees
    WHERE department_id = dept_id;
END //

DELIMITER ;
```

### Calling a Stored Procedure

```sql
CALL GetEmployeesByDepartment(2);
```

### Benefits

- Reduces **network traffic**  
- Ensures **consistency** of operations  
- Improves **security** by encapsulating queries

## User-Defined Functions

### What is a UDF?

- Functions return a **single value** or **table**  
- Can be used in `SELECT`, `WHERE`, `JOIN` clauses

### Example: Scalar Function (Return Single Value)

```sql
CREATE FUNCTION GetFullName(first_name VARCHAR(50), last_name VARCHAR(50))
RETURNS VARCHAR(100)
DETERMINISTIC
BEGIN
    RETURN CONCAT(first_name, ' ', last_name);
END;
```

### Using the Function

```sql
SELECT GetFullName(name, 'Smith') FROM employees;
```

### Table-Valued Function (Return Table)

```sql
-- PostgreSQL Example
CREATE FUNCTION GetEmployeesByDept(dept INT)
RETURNS TABLE(id INT, name VARCHAR)
AS $$
BEGIN
    RETURN QUERY
    SELECT id, name FROM employees WHERE department_id = dept;
END;
$$ LANGUAGE plpgsql;
```

## Triggers

### What is a Trigger?

- A trigger **automatically executes** when a specific event occurs on a table  
- Useful for **auditing, validation, or cascading actions**

### Types of Triggers

- `BEFORE INSERT`  
- `AFTER INSERT`  
- `BEFORE UPDATE`  
- `AFTER UPDATE`  
- `BEFORE DELETE`  
- `AFTER DELETE`

### Example: Audit Trigger

```sql
CREATE TABLE employee_audit (
    employee_id INT,
    old_salary DECIMAL(10,2),
    new_salary DECIMAL(10,2),
    changed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TRIGGER before_salary_update
BEFORE UPDATE ON employees
FOR EACH ROW
BEGIN
    IF OLD.salary <> NEW.salary THEN
        INSERT INTO employee_audit(employee_id, old_salary, new_salary)
        VALUES (OLD.id, OLD.salary, NEW.salary);
    END IF;
END;
```

- This trigger logs **salary changes automatically**.
